🏗️ Infrastructure & Architecture

🐳 Docker Services

  • Redis - Session store, pub/sub, caching
  • Node.js Server - Horizontal scaling support
  • React Client - Nginx serving build
  • Nginx - Reverse proxy, SSL, load balancing

⚙️ Performance Features

  • Lazy loading for all game components
  • Code splitting by route
  • Redis caching for game state
  • Gzip compression
  • PWA with offline support
  • WebSocket binary protocol
  • Intersection Observer viewport loading

🔒 Security Layers

  • Transport: HTTPS/WSS (TLS 1.3)
  • Auth: JWT + refresh tokens
  • Rate limiting: 10 actions/sec
  • Input validation: Length/type/sanitization
  • Timestamp validation: Anti-tamper
  • Server-side logic: ALL calculations
  • Action cooldowns: Lockout penalties
  • CORS: Whitelist only

🚀 Quick Start Commands

# Setup
chmod +x scripts/setup.sh
./scripts/setup.sh

# Development
npm run dev              # Concurrent client + server
npm run server:dev       # Server only
npm run client:dev       # Client only

# Production
docker-compose up -d     # Full stack
docker-compose up -d --scale server=3  # Scale horizontally

# Utilities
npm run redis:flush      # Clear Redis cache
npm run lint            # ESLint check
npm run format          # Prettier format
